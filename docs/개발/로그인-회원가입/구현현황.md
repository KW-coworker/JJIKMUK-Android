## 통신과 세션 구조

- `data/remote/BackendServer.kt`: debug/release 공통 `https://43.203.42.36/`. 별도 OCR/RDS 주소에 직접 접속하지 않는다. HTTPS 검증 유지. 과거 auth-api.properties의 baseUrl·scanner-ocr.properties 팀 토큰은 사용하지 않는다.
- `feature/auth/data/HttpAuthRepository.kt`: 명세별 성공 상태/본문 검사, 구조화 오류, 취소 전파, 무분별한 재전송 차단. Google ID Token/연결 증명/이메일 증명/서비스 Access/Refresh를 구분한다.
- `feature/auth/session/EncryptedSessionStore.kt`, `AndroidSessionKeyProvider.kt`: 앱 보안 저장소. 민감 토큰을 로그·분석 이벤트·문서에 남기지 않는다. Refresh 요청 전 진행 상태를 기록하고 결과 불명 상태를 복원하면 재로그인한다.
- `AuthSessionManager`, `AuthenticatedRequests`: 한 번의 갱신을 공유하고 이전 계정/토큰의 늦은 응답을 차단한다. 명확한 읽기 재시도와 변경 요청의 결과 재확인을 구분한다.
- `AuthorizedOperations`: OCR/챗봇 처리 요청은 전송 전 만료 확인, 전송 후 401은 동일 세션에만 반영하고 자동 재전송하지 않는다. 모든 401(예: 잘못된 로그인 비밀번호)을 전역 로그아웃하지 않는다.
- 갱신 소비 여부 불명 시 기존 Refresh 반복 금지. 네트워크/503 일반 조회 실패를 토큰 무효로 취급하지 않는다. 사용자에게 서버 로그아웃 완료를 확인했는지 별도로 표시한다.

## 이메일·입력·최종 제출

`EmailVerificationController`는 이메일/목적별 증명, 단조 시각 기반 타이머, 서버 오류·쿨다운·OTP 횟수를 관리한다. 실제 성공 전 OTP 단계로 이동하지 않는다. 서버 5xx와 일반 결과 불명 안내를 구분하고 버튼/키보드 제출을 대기 시간 동안 막는다. 대기 종료 후 자동 요청하지 않는다.

가입·재설정 증명은 서로 바꾸어 쓸 수 없다. 최종 닉네임 중복은 다른 입력 유지, 증명 만료는 입력을 보존한 재인증, 제출 결과 불명은 증명 반복 소비 없이 로그인/재인증 복구. 가입 응답은 자동 로그인 세션으로 쓰지 않는다.

새 비밀번호는 ASCII 영문·숫자 포함 8~72자, 특수문자 선택. 기존 로그인은 새 생성 규칙을 강제하지 않는다. 조건 변환은 [서버코드 매핑](가입조건-서버코드-매핑.md)을 사용한다. 알 수 없는 코드/복수 채식값을 조용히 제거하지 않는다.

## 추가 프로필·사진

미완료 Google 사용자는 기존 닉네임·조건·최종 확인 UI를 재사용하고 별도 ViewModel에서 POST /profile/complete를 호출한다. 일반 가입 OTP/signup을 다시 실행하지 않는다. 선택하지 않은 조건도 허용하며, 화면에서 수정하지 않는 diseases/dislikedIngredients는 보존한다. GET me로 완료 확인 후 홈에 진입한다.

사진 원본은 최대 20MiB 읽기·EXIF 회전 보정·최대 변 2048 축소·JPEG 재인코딩으로 2MiB 제한에 맞춘다. 업로드 multipart 필드는 `file`, 서버 사진 조회는 인증된 바이너리다. 공개 이미지 캐시에 토큰이나 계정 사진을 섞지 않는다.

가입 임시 사진은 **최종 제출 직전** noBackupFilesDir/signup-photos에 저장한다. 제출 전 선택만 한 상태까지 영속 저장하지 않는다. 파일명은 정규 이메일의 해시, 가입 성공 시 userId 결합. 해당 계정 로그인 후 서버 사진을 먼저 확인하고 사용자 선택으로 저장하여 다른 기기의 사진을 자동 덮어쓰지 않는다. 업로드 응답 유실 시 GET으로 재확인한다. 보류 시 임시 파일 유지, 성공/명시적 삭제 시 임시 파일만 정리. 계정 변경 시 이전 사진/응답을 차단한다.

## 마이페이지에 이미 연결한 동작

본인 식이조건은 `SelfDietConditionRoute`에서 GET me 후 변경한 allergies/specialDiet만 PATCH한다. 전체 해제=null, 나머지 필드는 생략. 응답 유실은 GET 재확인, 같은 값이 이미 저장됐으면 재전송하지 않는다. 초안은 메모리 보관이며 계정 변경 시 폐기한다. 본인 데이터와 소유자 없는 로컬 가족 정보를 혼합하지 않는다.

계정 보안은 명시적 동의/입력 후 비밀번호 변경·탈퇴 API의 성공을 확인하고 세션/완료 화면을 처리한다. Google 전용 계정에 일반 비밀번호 변경을 제공하지 않는다. 가족 CRUD HTTP가 있다는 이유로 가족 화면까지 완료로 보고하지 않는다.
