# API 명세 읽는 순서

이 폴더는 **요청·응답 계약**을 보관한다. 정책 결정/백엔드 회신은 [로컬 협의안](../협의/로그인-회원가입-백엔드-협의안.md), 현재 배포 응답은 [검증 기록](../검증/2026-10-31-인증-실서버-점검.md), 앱 구현은 [개발 현황](../개발/로그인-회원가입/구현현황.md)에 둔다.

## 출처와 우선순위

2026-10-31 확인 시 백엔드 main `7dd4273ee456329593a82b2b60934ef1b8c20240`은 사용자 제공 `f49478e`보다 merge 1개 앞서고 파일 차이는 없었다. 이것은 **당시 저장소 확인 기록**이며 지금 서버에 해당 커밋이 배포됐다는 뜻은 아니다.

`backend/`의 원문 5개는 [출처·SHA-256](backend/source-manifest.json) 기준 그대로 보관한다. 파일명/내용을 바꾸지 않아 원문 상대 링크와 해시를 유지한다. 자동 최신화되지 않으며 다음 동기화는 커밋 비교 후 진행한다.

- 인증 v2는 구형 24시간/Refresh 없음/자동 Google 연결/로컬 사진·가족 설명보다 우선한다.
- 기관 이전 TEAM_DELIVERY에 따라 현재 앱 주소는 `https://43.203.42.36/`, OCR은 로그인 Bearer JWT. 원문에 남은 과거 Tailscale/팀 토큰 주소를 현재 설정으로 복사하지 않는다.
- [백엔드 10월 28일 검증 보고](backend/staging-integration-20261028.md)는 당시 기록이다. 최신 실제 응답은 검증 폴더의 점검 기록을 확인한다.
- 원래 작업 폴더의 독립 수정본 인증 명세는 문서 정리 시 보존했다. 구현 기준은 인증 worktree의 코드·위 원문이며 폴더 간 차이를 무조건 덮어쓰지 않는다.
