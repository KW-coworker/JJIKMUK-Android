## 겹치지 않게 유지하는 기준

- 정책·회신 초안·백엔드 요청 목록은 **협의안만** 수정한다.
- 실제 관찰 응답·테스트 결과는 **검증 기록만** 수정한다. 요청 초안을 복사하지 않는다.
- 코드 구조·구현 범위는 **개발 문서**, 다음 시작점은 **인수인계**에 둔다. 인수인계에 여러 CURRENT SNAPSHOT이나 과거 진행 일지를 쌓지 않는다.
- API 계약과 실제 배포 결과가 다르면 원문을 임의 수정하지 않고 검증 기록에 차이를 남긴다.
- `API/backend/`는 출처·해시를 가진 원문 보관소이므로 원래 파일명과 내용을 유지한다. 읽기 쉬운 한글 안내는 API/README에서 제공한다.
- 인수인계·협의·받은자료는 `.git/info/exclude`로 제외한다. 실제 토큰·비밀번호·개인 설정은 공유 문서에 쓰지 않는다.
